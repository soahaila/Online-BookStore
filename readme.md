# BookVerse - Interactive Online Bookstore

This is a fully responsive, interactive landing page for an online bookstore, built with Vanilla HTML, CSS, and JavaScript.

## Features Implemented
1. **Responsive Design**: Mobile-first approach with a hamburger menu and CSS Grid/Flexbox layouts.
2. **Sliding Cart (Left)**: A dynamic shopping cart that slides in from the left, fully managing quantities and item removal.
3. **LocalStorage Integration**: Cart items are saved in the browser, persisting through page reloads.
4. **Modal Popups**: Click "View Details" on any book to see its description in a popup.
5. **Dark/Light Mode**: Toggle between themes, saved to local storage.
6. **Form Validation**: Real-time JavaScript validation on the contact form.
7. **Interactive Dropdowns**: Custom `<details>` tags for exploring genres with smooth animations.

## Project Structure
- `index.html`
- `css/style.css`
- `js/script.js`
- `images/` (uses unsplash placeholder URLs for demonstration)

## How to Run
